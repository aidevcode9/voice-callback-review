# Workflow selection

Status: configure during intake after identifying the project type and initial scope, before implementation.

The [project-workflow](../.agents/skills/project-workflow/SKILL.md) skill coordinates substantive work. The [profile](../.codex/workflow-profile.md) owns project-specific checks, available skills, and constraints. The sibling project-intake skill gathers initial context and configures both.

For each substantial task, inspect relevant pstack and house skills and record the choice. Refine this record when the stack or risks change.
