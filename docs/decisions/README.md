# Decision records

Create a decision record for a significant choice whose reasoning would otherwise be lost. Routine implementation choices can stay in the feature specification.

Name records `ADR-001-short-name.md`. Include the date, status, context, options, chosen approach, consequences, and superseded decisions. Link the feature and evidence that motivated the choice.

- [ADR-001: text-first review workspace](ADR-001-text-first-review-workspace.md) records the owner-approved stack direction, scope split and final audio sequencing.
